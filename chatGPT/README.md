# AUTO SELECT - 新車販売ECサイト（ロリポップ向け）

## 動作環境
- PHP 8.0以降推奨（PDO MySQL、mbstring）
- MySQL
- ロリポップ！のPHP/MySQL対応プラン

## 設置手順
1. ロリポップのユーザー専用ページでMySQLデータベースを作成し、ホスト名・DB名・ユーザー名・パスワードを確認します。
2. `config.php` の4項目を実際の接続情報に書き換えます。
3. phpMyAdminで対象データベースを選び、`schema.sql` をインポートします。
4. このフォルダ内のファイルをFTP/SFTPでサイト公開フォルダ（通常は `public_html` 相当の設定先）へアップロードします。
5. ブラウザで `index.php` を開き、一覧・詳細・カート・申し込みをテストします。
6. 管理者を作成します。ローカルのPHP環境で `php create_admin_hash.php 管理者名 '12文字以上の強いパスワード'` を実行し、表示されたINSERT文をphpMyAdminで実行します。ローカル実行できない場合は、同じハッシュを生成できる安全なローカル環境を利用してください。`create_admin_hash.php` を公開サーバーで開いてパスワードを作らないでください。
7. 動作確認後、`create_admin_hash.php` は必ずサーバーから削除します。`schema.sql` や `config.php` がWebから取得できないことも確認してください。

## URL
- トップ：`/index.php`
- 車両一覧：`/cars.php`
- 管理者ログイン：`/admin/login.php`

## 重要な注意
- サンプル車両は架空データです。実在車両の価格・画像・仕様に差し替えてください。画像は利用許諾のあるものを使用してください。
- このサンプルは購入「申し込み」を記録するもので、決済・契約・車両登録・納車管理は行いません。
- 本番公開前に、HTTPS、個人情報保護方針、利用規約、特定商取引法等の適用確認、バックアップ、管理者アカウント保護、メール通知、入力内容の運用ルールを整備してください。
- `config.php` は公開ディレクトリ外に置くのがより安全です。共有サーバーの制約に応じて配置を調整してください。
- `.htaccess` のディレクティブはサーバー環境によって調整が必要な場合があります。
- 管理画面の注文一覧には個人情報が表示されます。アクセス制限と運用ルールを必ず設定してください。
